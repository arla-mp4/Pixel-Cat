# Pixel Cat 

A little pixel-art cat that dances on screen. I made this project to experiment with pixel art, CSS, and JavaScript animations.

## Version 1

The first version includes:
- A custom pixel-art cat
- A continuously looping dance animation
- Blinking eyes
- A pink color palette
- A little bow and heart details
- A simple background with sparkles

## Built With

- HTML
- CSS
- JavaScript
- HTML Canvas

## Running the Project

Open `index.html` in a browser to see the cat.

## What's Next?

I'll probably keep adding details and animations as I work on it. This is just the first version!
